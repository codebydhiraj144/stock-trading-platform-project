# 📈 Stock Trading Platform (Zerodha Clone)

A comprehensive Full-Stack Web Application inspired by Zerodha. 
This platform simulates a real-world trading experience with a landing page, user dashboard, and a robust backend.

---

## 🏗️ Project Structure
The project is divided into three main components:
* **`fronted`**: The landing page built with React.
* **`dashboard`**: The trading interface (Holdings, Positions, Watchlist).
* **`backend`**: Node/Express server with MongoDB schemas.

---

## 🛠️ Tech Stack

### Frontend & Dashboard
* **React.js**: For building a dynamic UI.
* **React Router**: For seamless navigation.
* **Chart.js**: To visualize stock data.
* **Bootstrap**: For responsive styling.

### Backend
* **Node.js & Express**: Handling API requests.
* **MongoDB & Mongoose**: Managing stock and user data.

---

## 🚀 Features
- **Modern Landing Page**: Clean, professional UI for the home, pricing, and about pages.
- **Real-time Dashboard**: View current holdings and market positions.
- **Stock Watchlist**: Keep track of your favorite stocks.
- **Order Execution**: Simulate buying and selling with a "Buy/Sell" window.
- **Data Visualization**: Charts to track portfolio performance.
